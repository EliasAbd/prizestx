PrizeSTX – Prize-Linked Savings Contract
PrizeSTX incentivizes saving by pooling user deposits and distributing periodic rewards to randomly selected participants.
All deposits remain withdrawable except during active draw cycles.

Core Capabilities
- Deposit STX to enter prize rounds
- Random, fair winner selection
- Non-winners keep deposits
- Prize pool grows with participation
- Withdraw outside active draw phases

Key Functions
deposit, withdraw, draw-winner, claim-prize, get-user-balance, get-prize-pool
